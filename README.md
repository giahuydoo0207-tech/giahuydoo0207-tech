## Selected Projects

### [NIVEX](https://github.com/giahuydoo0207-tech/NIVEX-FLUTTER)

A recipient-facing Flutter MVP for exploring USDC wallet activity, remote jobs, and a simulated USDC-to-VND cashout flow. The current build uses demo data and Solana Devnet labels, with on-device biometric authentication and tested fixed-precision money handling.

### [NIVEX Business](https://github.com/giahuydoo0207-tech/NIVEX-BUSINESS)

A responsive Next.js portal for organization registration, contractor records, remote job posts, USDC invoices, and a simulated payment checkout. Records are currently stored in the browser; wallet signing and Solana verification remain future work.

[Live demo](https://nivex-business.vercel.app)
